
# SMARTDRONEDELIVERY
## Nền tảng quản lý giao hàng bằng Drone tích hợp AI

### 1. Giới thiệu đề tài
SmartDroneDelivery là nền tảng hỗ trợ quản lý hoạt động giao hàng bằng Drone, giúp quản lý khách hàng, đơn hàng, kiện hàng, trạm giao nhận và quá trình giao hàng.

### 2. Mục tiêu đề tài
- Xây dựng hệ thống quản lý giao hàng bằng Drone.
- Quản lý thông tin khách hàng và đơn hàng.
- Theo dõi trạng thái giao hàng.
- Quản lý trạm Drone.
- Ứng dụng AI để hỗ trợ dự đoán thời gian giao hàng và phân tích dữ liệu.

### 3. Đối tượng sử dụng
- Customer: Khách hàng.
- Dispatcher: Nhân viên điều phối.
- Station Operator: Nhân viên quản lý trạm.
- Logistics Manager: Quản lý logistics.
- System Administrator: Quản trị viên hệ thống.

### 4. Các chức năng chính
1. Quản lý tài khoản.
2. Quản lý khách hàng.
3. Quản lý đơn hàng.
4. Quản lý kiện hàng.
5. Quản lý trạm Drone.
6. Theo dõi giao hàng.
7. Xác nhận giao hàng.
8. Báo cáo và thống kê.
9. Hỗ trợ AI.

### 5. Công nghệ sử dụng
- Frontend: ReactJS.
- Mobile: Flutter.
- Backend: ASP.NET Core Web API.
- Database: PostgreSQL.
- Real-time: SignalR.
- AI: Phân tích dữ liệu và dự đoán.
- Công cụ: GitHub, Jira, Confluence, Figma, Docker.

### 6. Phạm vi đề tài
Tập trung xây dựng nền tảng quản lý quy trình giao hàng từ lúc tạo đơn, xử lý đơn, phân công giao hàng, theo dõi đến khi xác nhận kết quả giao hàng.

### 7. Kết quả dự kiến
- Website quản lý giao hàng.
- Ứng dụng Mobile.
- Backend API.
- Cơ sở dữ liệu.
- Chức năng theo dõi giao hàng.
- Dashboard thống kê.
- Chức năng hỗ trợ AI.
- Tài liệu và mã nguồn dự án.
