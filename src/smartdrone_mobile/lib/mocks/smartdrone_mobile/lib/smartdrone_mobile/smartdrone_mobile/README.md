
# SmartDroneDelivery Mobile

Ứng dụng Flutter thuộc dự án SmartDroneDelivery.

## Mục tiêu
- Khởi tạo cấu trúc ứng dụng Flutter.
- Định nghĩa model đơn hàng.
- Xây dựng Repository và Mock Repository.
- Hiển thị danh sách đơn hàng bằng dữ liệu mẫu.

## Cấu trúc
- lib/models: Mô hình dữ liệu.
- lib/repositories: Hợp đồng truy xuất dữ liệu.
- lib/mocks: Dữ liệu mô phỏng.
- lib/main.dart: Điểm khởi chạy ứng dụng.

## Lưu ý
Source code hiện sử dụng dữ liệu mẫu.
Cần tạo project Flutter hoàn chỉnh và kiểm thử
trên emulator trước khi xác nhận hoàn thành.
